## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executor tools bundled together with a universal loader for Windows desktop, making it easy to manage and switch between multiple executors.

### Which executors are included in XCutors?

The collection includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader that ties them all together.

### Is XCutors free to use?

XCutors itself is free to download and use as a loader and manager. Individual executors may have their own licensing or pricing models.

### What operating systems are supported?

XCutors is designed exclusively for Windows 10 and Windows 11 desktop environments. macOS and Linux are not supported.

### How do I update the executors?

The universal loader includes an auto-update feature. Simply open xcutorsLoader and it will check for and apply updates to all bundled executors automatically.

### Can I add my own Lua scripts to the script hub?

Yes. You can place custom .lua files in the 'scripts' folder inside the XCutors directory. They will appear in the script hub upon refresh.

### Why does my anticomponent flag the executor?

Some anticomponent programs may flag script executors as potentially unwanted programs due to their nature of injecting into other processes. You may need to whitelist the XCutors folder in your anticomponent settings.

### Do I need to run XCutors as Administrator?

Yes, running as Administrator is recommended so the executors can properly attach to the Roblox client process.

### How do I switch between executors?

Open xcutorsLoader and use the executor selection panel on the main dashboard. You can switch between Volt, Synapse Z, Potassium, and Wave with a single click.

### Where can I find scripts to use?

XCutors includes a built-in script hub with popular community scripts. You can also find scripts on community forums, Discord servers, and script-sharing websites.
